Pembuktian Pertanyaan 4: ID Selector vs Class Selector

Elemen di bawah ini memiliki atribut id="paragraf-1" (merah, 20px, bold) dan class="text-paragraf" (biru, 14px, normal):

• Ini adalah elemen: <p id="paragraf-1" class="text-paragraf">
Hasil Tampilan: Warna teks adalah MERAH dan ukuran teks 20px Bold.

Penjelasan Teknis: ID selector memiliki nilai spesifisitas (0, 1, 0, 0) yang jauh lebih tinggi daripada Class selector (0, 0, 1, 0). Walaupun deklarasi class ditulis setelah ID di CSS, aturan dari ID selector akan tetap dimenangkan dan diterapkan oleh browser.
